Data Architecture

Medallion Architecture

The lakehouse pattern powering modern data platforms — Bronze → Silver → Gold.

🥉
Bronze Layer
Raw / Landing
Raw ingested data as-is from source systems. No transformation. Full audit trail. S3 / Snowflake raw schema.
🥈
Silver Layer
Cleaned / Conformed
Deduped, validated, and standardized data. dbt models apply business rules. Data Quality checks run here.
🥇
Gold Layer
Business / Serving
Aggregated, analytics-ready marts. Star Schema, fact & dimension tables powering dashboards and reports.

PROJECT 01 · FEATURED
Airbnb Data Platform — End-to-End Analytics
Built a production-grade analytics platform modeled on Airbnb's data infrastructure. Ingested raw listings, bookings, and reviews data from multiple sources into AWS S3 as landing zone. Snowflake served as the cloud data warehouse with staging, integration, and presentation layers. dbt handled all transformations — implementing SCD Type 2 for historical tracking, fact tables for bookings/revenue, and dimension tables for hosts, listings, and locations. Medallion architecture (Bronze → Silver → Gold) enforced data quality and enabled self-service analytics.

PROJECT 02
Real-Time Streaming Pipeline — Kafka + Snowflake
Architected a low-latency streaming pipeline using Apache Kafka as the distributed event broker. Python producers simulate real-time events (transactions, user activity). Kafka-Python consumers process, deserialize, and validate stream records before sinking to Snowflake for near-real-time analytics. Implemented topic partitioning, consumer group offset management, and schema-based message validation.
